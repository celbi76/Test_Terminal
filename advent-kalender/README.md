# Klartext Advent

Digitaler Adventskalender als installierbare Web-App. Kein Build, kein Backend.

Start lokal: `cd advent-kalender && python3 -m http.server 8000`, dann http://localhost:8000 öffnen.
Hosting: den Ordner auf Vercel, Netlify oder GitHub Pages legen (HTTPS nötig für Installation und Teilen).
Vor dem 1. Dezember: Einstellungen, Testmodus.
Texte anpassen: content.js.
